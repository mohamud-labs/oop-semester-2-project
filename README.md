# 📦 Inventory Management System

### Object-Oriented Programming (OOP) – Semester 2

Welcome to my second-semester university project at Bahria University, Islamabad.

## 📌 Project Overview

The Inventory Management System is a C++ application designed to manage products, customers, suppliers, inventory and sales orders.

The program allows users to enter information, manage products, create customer orders and generate inventory and sales reports.

## 🚀 Features

- Admin and customer information
- Product management
- Category and supplier management
- Inventory management
- Product searching
- Customer order processing
- Automatic price calculation
- File handling (save and read inventory)
- Inventory and sales reports

## 🛠️ OOP Concepts Used

- Classes and Objects
- Inheritance
- Encapsulation
- Polymorphism
- Function Overriding
- Constructors
- Pointers
- Vectors
- File Handling
